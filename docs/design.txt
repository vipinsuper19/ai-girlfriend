Design the complete Android mobile application UI/UX for an AI Girlfriend / AI Companion platform.

The design must be production-ready, modern, emotionally engaging, premium, and technically realistic for implementation using **Kotlin + Jetpack Compose + MVVM**.

## PRODUCT

The application is an AI companion platform where users can create and interact with a personalized AI girlfriend.

The experience should feel:

* Warm
* Personal
* Premium
* Modern
* Emotionally engaging
* Trustworthy
* Private
* Simple to use

Avoid making the application look like a generic chatbot, dating app, or social-media clone.

The AI companion should feel like a persistent personal relationship rather than just an AI chat interface.

---

# ANDROID DESIGN REQUIREMENTS

Design specifically for Android phones.

Primary design target:

* 360–430dp width
* Modern Android phones
* Portrait orientation
* Material 3 principles
* Edge-to-edge layouts
* Accessible touch targets
* Responsive Compose-friendly layouts
* Light and dark themes

Use Android-native interaction patterns wherever appropriate.

Do not create desktop layouts.

---

# ONBOARDING

After authentication, design a short onboarding experience.

The purpose is to introduce personalization without overwhelming the user.

Possible screens:

### Onboarding Welcome

Explain that the user can create a companion that matches their personality and preferences.

### Companion Personality

Allow selection/customization of personality characteristics.

Examples:

* Caring
* Playful
* Romantic
* Confident
* Calm
* Intelligent
* Funny

Use attractive selectable cards/chips.

### Companion Appearance

Create a visual selection/customization experience for the companion.

The UI should feel premium and respectful.

### Relationship Preferences

Allow the user to define the kind of companion relationship they want.

### Finalization

Show a companion preview and CTA:

"Meet Your Companion"

Transition into the main application.

# UX PRINCIPLES

Follow these principles:

1. One primary action per screen.
2. Minimize cognitive load.
3. Keep onboarding short.
4. Make the AI companion the emotional center of the product.
5. Use progressive disclosure for advanced settings.
6. Avoid clutter.
7. Use subtle animations and transitions.
8. Make privacy and memory controls easy to understand.
9. Maintain consistent navigation.
10. Make every interaction feel responsive.

---

# VISUAL DIRECTION

Use a premium, modern, emotionally warm visual language.

Prefer:

* Soft depth
* Refined gradients used sparingly
* Beautiful companion imagery
* Rounded cards
* Elegant typography
* Subtle micro-interactions
* Generous spacing
* High-quality avatars
* Sophisticated surfaces

Avoid:

* Excessive pink
* Cartoonish UI
* Cheap dating-app aesthetics
* Excessive glassmorphism
* Excessive gradients
* Clutter
* Generic AI robot imagery
* Generic chatbot UI
* Excessive decorative hearts

The final result should look like a **serious premium consumer technology product with an emotionally personal experience**.

Design the system so that additional features can be added later without redesigning the entire application.
